Dataset: Spam Emails

Problem Type: Classification Problem.  

Target Variable: The Category column, which classifies emails as "spam" or "ham".  

Problem Statement: The objective is to train a machine learning model to distinguish between legitimate emails (ham) and junk emails (spam). The model learns patterns from the Message text to predict the correct category for new, incoming emails.
